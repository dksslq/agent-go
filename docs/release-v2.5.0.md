# v2.5.0：轮次自纠错与单个 JSON 会话文档

修复长期自主运行被单次模型缺陷终止的问题，并按用户要求重构持久化格式：会话文件从"空行分隔的逐行日志"改为**一个 JSON 文档**，删除每条检查点的 SHA256 校验。保持 Go 标准库、单二进制、无临时文件、无固定大小上限。

## 自主运行：坏工具调用不再杀死进程

**报告的缺陷**：长时间运行后出现 `Runtime error: tool call "call_00_…" has incomplete or non-object JSON arguments`，程序直接退出。根因在流式收尾（`openai.go` 的 `finishTools`）：当 `finish_reason=tool_calls` 或 `[DONE]` 到达时，累积的工具参数必须是完整 JSON 对象。长上下文下模型偶发输出被截断的参数、非对象参数或空参数（`call_00_` 前缀是兼容服务端合成的 ID）。原先"不执行半个工具调用"的守卫正确拒绝了执行，但错误一路冒泡，在 `-once` / `-pipe` 自主模式下直接终止进程——一次模型失误换掉整段长任务的会话。

**修复**：新增可重试轮次分类（`errRoundRetry`）。模型输出缺陷（参数不完整/非对象、缺 ID、重复 ID、空响应、`finish_reason` 未完成、工具增量损坏）与断流（EOF 未收尾、读错误、流空闲超时）标记为可重试；认证、请求拒绝、用户取消、输出与检查点失败保持致命。可重试失败以 `[Turn aborted: …]` 原样记录进历史，推理循环携带该反馈**立即重新请求**——模型读到自己的失败标记即可自行纠正；连续 5 次失败才按原错误退出。任何已执行的工具不会被重放：被中止的轮次根本没执行任何调用。交互模式行为不变（原本就不会因轮次错误退出），自主模式获得同样的韧性。

验证：回归测试复现报告的确切场景（截断参数 + `finish_reason=tool_calls` + `[DONE]`），确认第二次请求携带中止标记、轮次自愈、进程存活。

## 会话格式 v5：一个 JSON 文档

**动机**：v4 每条提交为 `{"checkpoint":…,"sha256":…}` 单行记录，以 `\n` 分隔——文件呈现为"空行隔开的一行行记录"，人不可读；每条都做 SHA256，防的是位翻转与外部篡改这类外因，用户裁定不值得维护。

**新格式**（`sessionVersion=5`）：

```json
{
  "version": 5,
  "m0": {"role":"system","content":"…"},
  "m1": {"role":"user","content":"…"},
  "state": {"base":0,"cursor":1,"memory":""}
}
```

- 消息按**绝对索引**为键（`"m13"`），`history_read` 直接按键取数；
- `state` 成员记录 base、cursor 与语义记忆；`memory_edit` 追加新的 `state`（JSON 允许重复键，后一个生效，任何标准解析器读取结果一致）；
- 加载语义与用户描述一致：**按游标选择**，仅系统消息与 `cursor` 之后的活跃尾部进入 RAM，文档本身保留全部原文供 `history_read` 回溯；
- 每个工具轮次**追加**新成员并重新闭合文档（截掉 `}`、写入 `,\n  "m…"…\n}`、sync）：不重写既有字节、写放大恒定、失败回滚到上一提交位置；
- 崩溃撕裂的尾部留下未闭合成员，流式读取停在最后一个完整成员处（EOF 判定为撕裂、语法错误判定为损坏）；下次写入时自动清掉残尾；
- 不再有每条 SHA256：撕裂由未闭合结构捕获，语法损坏仍然致命，等长载荷改写按用户裁定接受。

**兼容**：v4 日志、v3 对象与旧数组照常加载（v4 的 `sha256` 字段接受但不再校验）。`-continue` 旧文件时保留原字节、在其后追加 v5 增量文档（键从旧计数继续、base 不变）；`/save` 另存生成干净的 v5 文档。旧格式写入器已删除，读取器保留。

## 其他

- 系统提示词补充：被标记中止的轮次没有执行任何工具调用，应正确重新发起。
- `checkpointSession` 在无新消息且无状态变化时不再写空记录（原 v4 会写冗余条目）。
- 测试适配：日志回归测试改按 v5 撕裂语义（截断到成员内部）；校验和致命测试随特性删除；新增轮次自纠错与 v4→v5 迁移回归测试。

## 验证

本地验证通过：gofmt、go vet、全量测试含 race。回归覆盖：报告的截断参数场景自愈；v4 日志迁移（前缀字节不变、追加文档可续写、计数/base 正确）；旧 v3/数组加载；撕裂尾部忽略与保存时修复；快照保留压缩历史且不改写源文件；独占句柄下的并发 `history_read`。发布流程继续执行多系统 CI 与 Debian 打包；未连接真实模型服务。
