# v2.1.3：多行粘贴与资源清理

- 终端支持 bracketed paste：粘贴中的换行、缩进、转义及编辑字符作为文本保留，按 Enter 才发送。不完整粘贴不会发送。
- Alt+Enter 插入换行；兼容终端的 Shift+Enter。旧终端可用 `/paste` 输入多行，Ctrl+D 发送。多行正文不执行交互命令。
- Windows 启用并恢复输入、输出 VT 模式；Unix 不再把粘贴中的 CR 转为 LF。退出关闭粘贴模式并恢复终端设置。
- 修复失败请求的输入引用滞留、首次归档失败的临时文件残留、交互输出失败仍等待输入。未知键序列流式丢弃，不累积无用字符串。
- 普通输入保留首尾空白；重定向输入保留控制字符。默认不展示内部系统提示词，`-verbose` 仍可查看。
- 删除失效补丁与过期说明，补充 Codex 开发者署名。仍仅使用 Go 标准库，无进程全局互斥、粘贴大小限制或新依赖。

验证包含真实 Linux PTY 的完整 CLI、60 KB 多行粘贴、截断粘贴、显式多行输入、输出失败和归档回滚；完整竞态测试、Go 1.21 兼容检查与跨平台构建由 CI 执行。

没有粘贴协议的终端无法可靠区分粘贴回车与键盘 Enter，需使用 `/paste`。键盘 Ctrl+C 保持中断语义；持续保存未经整理的完整历史仍需要相应磁盘空间，模型应按提示使用 `memory_edit`。
