# v2.1.0：自主运行与上下文生命周期审计

保持单二进制、Go 标准库和三个工具，修正自主执行、进程取消、流式 API、输出捕获及会话记忆的行为。

## 主要变更

- **退出与保存可编排。** `-once` 要求提供提示词；`-pipe` 保持助手正文在 stdout、日志在 stderr。API / 输入 / 保存失败退出 `1`，SIGINT 退出 `130`，SIGTERM 退出 `143`；单次模式不切换终端状态。每个工具轮次与用户轮次结束后保存检查点，保存失败停止当前推理。
- **完整输出可以留在文件。** `exec.output_file` 将合并输出写入新文件，回传路径、字节数和可选预览。`max_output_chars` 按 Unicode 字符限制预览，达到上限后继续排空输出并等待完成，避免把输出限长当成终止命令的条件。未指定输出文件或预览上限时仍完整内联回传。
- **整理记忆同时释放 RAM。** `memory_edit` 默认压缩已完成的历史，包括当前任务先前步骤，将原文移至私有临时存档；模型必须在完整记忆中保留任务目标、约束和后续工作。保存的 v3 文件仍含完整 transcript，加载兼容旧 v3 和消息数组。记忆编辑按调用顺序执行，游标不能拆开未完成的工具调用组。
- **流式响应明确完成后才能执行工具。** SSE 支持完整事件、多行 data、CR / LF 与乱序工具分片；损坏 JSON、断流、不完整或重复工具标识、模型长度截断都报告错误，不执行截断的工具调用。网络空闲超时覆盖连接、响应头与正文读取，支持 `0` 关闭；保留 HTTP 代理和 TLS 校验。
- **进程与输入生命周期修正。** 前台命令取消时在 Linux / macOS 终止进程组，Windows 终止直接子进程；后台启动回收进程资源。处理非换行结尾的输入、Ctrl+D、回车及信号，拒绝将特殊设备当作图片读取。
- **默认观察更简洁。** 默认工具日志只展示名称；`-verbose` 显示推理、参数和结果。模型、地址、密钥可由 `AGENT_MODEL`、`AGENT_API_BASE`、`AGENT_API_KEY` 设置，命令行覆盖环境默认值。主页重写为实际运行与部署说明。

## 升级时留意

`memory_edit` 省略 `cursor` 的含义变为压缩已完成历史。它可以压缩当前任务先前步骤；调用前应将用户目标、约束、证据与未完成事项写入 `memory`。游标继续使用完整 transcript 的绝对索引。

`-tool-call-idle-timeout` 保留为 `-stream-idle-timeout` 的别名，覆盖所有网络数据等待。`-extra` 仍可附加厂商参数，但不再允许覆盖 `model`、`messages`、`tools`、`stream`。旧会话保留原有系统提示词，新建会话采用新版规则。

没有自动重试或副作用事务保证。异常退出后核实已经执行的操作，再决定是否重试；多个进程应使用不同会话文件。临时存档在正常退出时清理，持久历史需要 `-save` / `-continue`，输出文件需要自行管理。

没有固定的工具轮数或默认输出大小上限。完整内联结果、活跃上下文和图片仍占用内存；长任务使用文件输出、主动整理记忆，并由运行环境管理资源和权限。

## 验证

本次新增回归覆盖真实子进程的输出与取消、SSE 完成与断流、存档与恢复、记忆压缩和顺序，以及 CLI 的退出码和信号。本地通过格式检查、`go vet` 和完整竞态测试（86 个顶层测试，覆盖率 67.2%）；Go 1.21.13 的检查和竞态测试通过；Linux / macOS / Windows × amd64 / arm64 六目标构建通过。CI 矩阵另行验证各平台运行时。

验证结果与发布产物以对应提交的 [GitHub Actions](https://github.com/dksslq/agent-go/actions) 和 [Release](https://github.com/dksslq/agent-go/releases) 为准。

用户输入和 API 正文保留原文，不再插入零宽字符或删除非终端正文的 ANSI 数据；`-pipe` 保留 stdin 空白。输出写入失败和已有空会话也按错误处理。
