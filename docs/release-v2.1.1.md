# v2.1.1：提示词精简与 Windows 会话占用

在 v2.1.0 的运行时审计之后，精简重复的工具描述、系统提示词和记忆报告，修正 Windows 同名会话的竞争行为。保持三个工具、单二进制与 Go 标准库。

也包含 [v2.1.0 审计](https://github.com/dksslq/agent-go/blob/main/docs/release-v2.1.0.md) 的全部修复：完整 SSE 校验、退出码与信号处理、进程回收、文件输出、磁盘历史存档，以及工具轮次检查点。

本地模拟 API 捕获实测：工具定义 JSON 从 3429 缩至 2047 字节，系统提示词 UTF-8 正文从 1363 缩至 697 字节，合计 4792 → 2744 字节，减少 42.7%。这些是字节数，不代表准确的 token 数。

- 工具名称、参数类型与必填字段保持兼容；删除重复描述和重复参数解析。提示词明确要求在里程碑、大量输出之后、历史重复之前整理记忆，并保留目标、约束、证据、文件路径和下一步工作。
- 每个工具轮次只在最后一个结果追加 `last_request_bytes`，报告上一次完整请求 JSON 的实际字节数。它不是 token 数、窗口上限或剩余容量；程序不据此设置固定压缩阈值。存档定位信息保留在记忆消息中，动态观测不改写稳定前缀。
- Windows 在启动时占用选定的写入会话文件，拒绝其他读写打开；同名竞争立即失败，不使用全局保存锁或自动重试。替换自己的快照时保留文件占用。因必要的 `FILE_SHARE_DELETE`，有删除权限的外部程序仍可操作路径；占用冲突不修改上一次有效快照。
- Windows 保存使用已持有句柄及 `FileRenameInfoEx`，要求文件系统支持 POSIX 替换；不关闭所有权句柄后再按路径重开。Unix 保持同目录快照替换。检查点不提供外部工具副作用的事务保证。

模型连接仍使用 OpenAI 兼容 HTTP / SSE。MCP stdio 是工具通信协议；新增模型传输必须先有具体的消息帧与调用语义，本次没有加入通用后端框架或第三方依赖。

旧会话保留自己的系统提示词，新建会话使用精简规则。`memory_edit`、`output_file`、退出码及完整 v3 会话格式延续 v2.1.0 的行为。

验证包括工具 schema / 请求大小、记忆压缩、Windows 实际文件占用与跨检查点竞争的回归测试。最终结果与产物以对应提交的 [GitHub Actions](https://github.com/dksslq/agent-go/actions) 和 [Release](https://github.com/dksslq/agent-go/releases) 为准。
